# Portfólio Pessoal

Portfólio pessoal desenvolvido com **HTML5 e CSS3**, com o objetivo de apresentar minhas informações, habilidades, conhecimentos e projetos acadêmicos desenvolvidos durante minha formação em Análise e Desenvolvimento de Sistemas.

## Tecnologias utilizadas

- HTML5
- CSS3

O projeto não utiliza JavaScript. O formulário de contato utiliza a validação nativa do HTML e o serviço [Formspree](https://formspree.io/) para receber e encaminhar as mensagens enviadas pelos visitantes.

## Projeto em destaque

### Escalonamento de Processos – FCFS

Projeto acadêmico desenvolvido na disciplina de Sistemas Operacionais, com implementação em linguagem C do algoritmo **FCFS (First Come, First Served)**.

O projeto tem como objetivo demonstrar o funcionamento do escalonamento de processos, organizando sua execução de acordo com a ordem de chegada.
