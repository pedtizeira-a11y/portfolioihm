# Portfólio pessoal

Portfólio em HTML e CSS para apresentar informações pessoais, habilidades e um projeto acadêmico de escalonamento de processos FCFS.

## Tecnologias

- HTML5
- CSS3

O site não utiliza JavaScript. O formulário de contato usa validação nativa do HTML e envia as mensagens pelo Formspree.



## Projeto em destaque

**Escalonamento de Processos:** projeto acadêmico de Sistemas Operacionais que implementa o algoritmo FCFS em C.
